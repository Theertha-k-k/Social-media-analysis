# Social-media-analysis

This project analyzes social media data to understand content performance, user engagement, audience behaviour, and sentiment patterns.  
Python libraries such as **NumPy, Pandas, Matplotlib, and Seaborn** are used for data cleaning, analysis, and visualization.  
Exploratory Data Analysis (EDA) is performed to identify trends across post types, content categories, countries, age groups, and verified accounts.  
Behavioral and sentiment analysis helps understand posting times, device usage, and audience reactions.  
The project provides meaningful insights and recommendations to improve social media engagement and content strategies.
